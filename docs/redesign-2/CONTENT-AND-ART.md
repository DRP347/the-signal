# Content and art contract

## Source previews

News records with no vetted body remain source links (or source excerpts when a preview was supplied). The exact collected title is preserved. A community submission title is not asserted to be the publisher's exact original title. Community dates are labeled shared/submitted; missing publication dates remain unknown. Original destination domains and collector names are distinct. No reading duration is fabricated. Optional AI output remains unverified and collapsed.

Advisory and incident records preserve structured official data, unknown fields, references and affected-version tables. Ranking reasons and collection timestamps remain available inside a native Sources & methodology disclosure.

## Full articles

`data/articles.json` is intentionally empty. `lib/article-content.ts` defines an explicit content type, author, deck, publication/review dates, rights basis and record, source links, and typed paragraph/heading blocks. Only a registered and structurally complete item reaches the full-reading template. An editor must verify accuracy, rights and substantive value; the structural guard cannot do that. Existing excerpts and optional AI summaries never qualify automatically. No database migration or change to ingestion is needed.

The full-reading component uses real paragraphs, headings and source notes; a 65ch measure; adjustable 19–20px reading text; keyboard-accessible Focus Mode and persistent larger text. The separate test fixture proves the renderer without inventing live editorial content. Its label is always visible, it is not a production route, and it is not inserted into the database.

## Original artwork

- DNS: simplified name lookup, returned address, then connection. Grounding: RFC 1034. A text diagram replaces tiny SVG labels on narrow screens. No specific provider, intervention point, enacted block or country process is asserted because the referenced report was unavailable to verify.
- Datacenter planning: papers, a dotted path and server cabinets. Caption explicitly calls this a conceptual metaphor. No claim about which authority transfers an application.
- Existing AI/device/code/security illustrations remain available only for matching topics. The universal globe fallback was removed. Other stories can remain text-led.
- The licensed-photo manifest and its verification gate remain intact. Natural approved image ratios are preserved. Broken images expose a readable fallback, caption and credit link.

All new SVG art is repository-native; there are no image-generation or external image-library dependencies. Font licenses and download provenance are in `public/fonts/source-manifest.json` and the two new OFL files. Retained original font files are not deleted, but unused Plex Sans is no longer loaded.
